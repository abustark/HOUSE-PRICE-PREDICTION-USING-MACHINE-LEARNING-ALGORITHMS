    Leakage Elimination Protocol

    • Outer 70/30 Split: Split strictly precedes any learned feature preprocessing.
    • Fold-Local Encodings: BHK medians, location frequencies, and StandardScalers are fitted inside each CV fold slice.
    • Explicit Schema: Supported area types are canonical; unsupported categories return 422 errors.

    Location-Grouped Stress Test

    • GroupKFold by Location: Evaluates models when predicting properties in entirely unseen localities.
    • Random Forest Group-CV R²: 0.719 (demonstrating expected penalty when locality is novel).
    • Safety Guard: Unseen localities trigger explicit notices in the response.
